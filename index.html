Gags Evolved

A Bondage Club addon that keeps gag silencing going past the game’s limit, so a heavier set of gags actually sounds heavier.

What it does

In the base game, silencing stops getting stronger once your total gag level passes a certain point. Gags Evolved carries on from there. Above level 20, speech fades out gradually. At level 40 and up, whatever the wearer types is sent as a quiet action line instead of chat text.

Level 12mmmmm mmmmm
Level 20 m m m m m
Level 30 m m
Level 40(An extremely soft, almost inaudible sound is heard from Lumi)

The same message, “hello there”, as the wearer’s gag level rises. The lines are examples.

It only changes your own speech, and only after you turn it on.

Install

Pick one method. The userscript is better for everyday use. The bookmark is a quick way to try it without installing anything.

Method 1: userscript (Tampermonkey or Violentmonkey)

  1. Install Tampermonkey or Violentmonkey in your browser.
  2. Open the install link. Your userscript manager shows an install page with a button.
  3. Reload Bondage Club.

Updates arrive by themselves each time the game loads, so you only install once.

Method 2: bookmark

  1. Drag this button to your bookmarks bar:
    Gags Evolved
  2. Open Bondage Club.
  3. Click the bookmark once the page has loaded. Do this every time you load the game.

If dragging doesn’t work, or you’re on a phone, copy the code below. Bookmark any page, edit that bookmark, and paste the code into its address field.

Using it

It starts switched off. In any chat room, type /gagfade on to switch it on and /gagfade off to switch it off. Your choice is remembered for your account in that browser, so people who only want it for certain scenes can turn it off between them.

Spotting other users

Hover the top of a character who is running Gags Evolved and a small GE badge appears. Hover the badge to see their version, whether the addon is on, and their current gag level and stage. The badge is purple when it’s on and grey when it’s off, and characters without the addon show none.

Everyone in the room can see that you run it, since that’s how users find each other.

Good to know

  • It only changes the messages you send while wearing the gags. It does nothing to anyone else’s speech.
  • Silenced messages don’t carry your original text, so anti-garble features, including the one in WCE, have nothing to reveal.
  • If you use WCE’s “Show sent messages while waiting for server” option, a dotted placeholder line stays in your own chat after a message is silenced. Only you see it, and switching that option off removes it.
  • Because updates load automatically, the addon’s code can change whenever its author publishes a new version. Only install addons from people you trust.

Planned

These are ideas the author is working toward. None of them has a date, and some may change or never ship.

  • Extra gags inside one slot. The game gives you three mouth slots. The plan is for each slot to hold several gags at once: click the slot, a window opens with the extra gags, and their levels add up for that slot. Other players still see the one real gag. This is also what makes level 40 reachable with everyday gags.
  • A settings menu in the game. A Gags Evolved screen under Settings, in the Extensions section like other addons have, so you can switch the addon on and off and adjust it without typing commands.
  • Settings that follow you. Right now your on/off choice is stored in one browser. The idea is to keep it with your account so it carries over to every device you play on.
